# Stellara

Think in signals. Solve 1,000 JavaScript puzzles in an electric observatory.

Electric blue glass, violet signals and console green.

## Includes

- 1,000 puzzle records across 50 chapters
- Mobile-first editor, progress map, local progress, hint and answer checking
- Separate free-play terminal and separate test terminal panel
- GitHub Pages workflow for `hassanireza/stellara`

## Runtime notes

This static GitHub Pages game has no server. JavaScript runs locally in the browser. Do not paste untrusted code into the free-play terminal.

## Local development

`npm ci` then `npm run dev`. Build with `npm run build`. The Pages workflow deploys the built `dist` directory from the `main` branch.
